About

01

I'm a graduate from the Applied Data Science & AI course at Breda University of Applied Sciences (BUas), currently working as a junior data engineer for the PlaySmart research project. My work focuses on building and maintaining the infrastructure for the PlaySmart esports analytics toolkit, including an ingress/egress server and a Nvidia Spark for model inference.

My graduation project was doing my graduation internship at The Hive, the esports lab behind the Breda Guardians. My thesis is about migrating an analytics toolkit from manual, USB-based deployment to a version-controlled workflow built on GitHub Actions and Docker.

Across my projects I keep ending up in the same spot: a process that works, but only by hand, and only for the person who built it. I like doing the part where that gets turned into something automated, documented and shared — a script, a pipeline, a container — that keeps working once I've moved on to the next thing.
